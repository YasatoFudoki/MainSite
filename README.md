# やさと風土記

茨城県石岡市八郷地区（旧八郷町・通称「やさと」）で活動する人・仕事・暮らしを記録し、伝えていくための地域情報サイトです。

- 活動一覧（カテゴリー別フィルタ、詳細モーダル）
- サイトについての紹介ページ
- 掲載申請 / お問い合わせフォーム（[Web3Forms](https://web3forms.com/) を利用）
- 免責事項

## 公開方法（GitHub Pages）

このリポジトリは `index.html` 1ファイルの静的サイトです。`.github/workflows/deploy.yml` により、`main` ブランチへの push で GitHub Pages に自動デプロイされます。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を `GitHub Actions` に設定してください。

## お問い合わせフォームについて

フォームの送信には [Web3Forms](https://web3forms.com/) の Access Key を使用しています（`index.html` 内 `WEB3FORMS_KEY`）。キーを変更したい場合は、Web3Forms でメールアドレスを登録し、発行されたキーに差し替えてください。
